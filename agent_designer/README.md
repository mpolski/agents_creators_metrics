# Agent Designer Instructions

This directory contains the configuration instructions for the Gemini Enterprise Agent Analytics and Creator Metrics agent.

## Usage

The [instructions.md](instructions.md) file is designed for configuring a **no-code agent** in the **Gemini Enterprise App Agent Designer**. 

To use these instructions:
1. Open the **Gemini Enterprise Console**.
2. Navigate to your agent's configuration page in the **Agent Designer**.
3. Open [instructions.md](instructions.md) and replace `<your_project_id>` with your actual Google Cloud Project ID.
4. Copy the entire contents of [instructions.md](instructions.md).
5. Paste it directly into the **Instructions** input field of your agent configuration.
